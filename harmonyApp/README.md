# UniTrading HarmonyOS 原生适配（开发中）

目标为 HarmonyOS 5/6 原生应用，最低兼容版本暂定 5.0.0(12)。这是一项早期迁移，不是完整交易软件。当前页面只显示“未连接”和开发状态，不读取任何真实账户数据，也不提供下单入口。

## 本次内容

- 新增独立的 Stage 模型工程和四个页面入口。
- 将现有 Kotlin 指标公式的一部分迁移到 ArkTS：SMA、EMA、BOLL、RSI、MACD、KDJ、ATR；数值行为与当前 UniTrading 公式对照。
- 迁移常用时间周期转换与收藏周期排序。
- 不依赖安卓 API；无券商、账号、数据库或下单实现。

## 不支持与限制

尚未实现 Tradovate 网页登录、行情 / K 线订阅、实时下单 / 撤单、止损止盈、账户级风控、图表绘制与绘图、VWAP 交易时段、持久化、主题和指标配置。请不要将此工程用于交易。

业务逻辑目前未与 Kotlin 共享，属于初步迁移。鸿蒙原生的数值采用 JavaScript number，接入交易逻辑前必须明确处理安全整数范围、定点金额和溢出，不能直接复用此处的展示计算执行订单。

## 编译和测试状态

本环境没有 DevEco Studio、HarmonyOS SDK、Hvigor 或真机：未编译 HAP，未进行 ArkTS 编译、模拟器或真机测试。项目结构与版本应以对应 DevEco Studio / HarmonyOS SDK 校验为准；发布或真机安装还需要开发者签名。

纯算法可以用 Node.js 24 运行 `node tests/run.mjs`，此检查不等同于 ArkTS 编译或鸿蒙设备测试。

## 后续迁移的主要边界

1. 在 DevEco SDK 下先验证工程入口、生命周期、权限和安全区。
2. 明确网络和 WebView 登录方案；单独适配 token 生命周期、证书与加密存储。
3. 行情、K 线以及交易日 / 美国夏令时使用券商数据，验证断线重连、缓存和时区。
4. 执行账户、持仓、挂单和历史的只读对账；再迁移下单、风控、括号单与异常恢复，并先在券商模拟环境逐项验证。
5. 将图表交互、显示与设置逐步对齐现有 Android/iOS/Windows 版本，最后签名、编译 HAP 并在真实设备上检查。
