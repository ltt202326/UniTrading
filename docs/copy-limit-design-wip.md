# 多账户限价跟单：开发中

基于 PR #11 与已有 Demo 跟单分支。此文件描述尚未完成的功能；新设置界面、订单状态处理和执行服务尚未接入运行中的跟单控制器，不得将本分支当作完整跟单版本。

## 已确认的交互与规则

- 用户分别选择主账户和多个跟随账户；账户可以属于不同 Tradovate Demo 登录。账户身份同时包含登录及子账户。暂不开放 Live。
- 每个跟随账户独立设置倍率、Micro 或 Standard 和最大张数；启动前不需要选择合约。
- 倍率按订单张数计算，小数向上取整。1 张 CL、倍率 1、选择 MCL 时为 1 张 MCL；1 张 MES、倍率 1、选择 ES 时为 1 张 ES。后者每张名义规模约为前者 10 倍，NES 转 ES 为 100 倍；必须让用户明确看到差异。上限不能因向上取整而突破。
- 仅识别已核实的合约系列及相同月份，未找到目标合约、行情或合约规格时停止对应账户，不替换其他月份。CL 和 MCL 的到期日并不完全相同；不能根据名称相同就假设交易时间或有效期相同。价格必须符合目标合约最小变动单位，不自动调整。
- 用户选择：跟随单先成交而主单未成交时暂停该跟随账户、提醒并保留已成交仓位和保护；若仍有未成交部分，只有确认撤销不会破坏保护时才撤销，否则停止并提示人工核对。主单先成交而跟随单仍有效时保留跟随限价单并提醒，不追市价；跟随单拒绝或状态未知时停止并核对，不重发。
- 主账户止盈/止损后，跟随账户仍有可完整归属的仓位时应关闭对应仓位；跟随账户已平仓时不发第二笔平仓单。仍在工作的跟随入场单须先安全撤销并等待确认；撤单可能与成交并发，不能假定撤单一定成功。所有退出单只能按确认的账户、订单、合约、方向、仓位和版本处理，关联不明时停止。
- 某个连接掉线时不能假定其券商挂单撤销或没有成交。暂停相关账户、保留订单标识并提醒；恢复后重新同步订单、成交、仓位和保护关系，未经核对不追单、不重新发送。

## 已实现的独立组件

纯计算组件覆盖产品映射、独立账户设置、按张数取整、入场成交差异、退出优先级、订单关联和持久化意图。限价单提交服务只用于离线模拟测试；未连接页面，也未接入实际运行控制器。服务对账户快照、保护单关联、报价和发送前版本作保守检查，并通过现有账户风控发送；下单意图须先持久化，未知结果不能自动重发。

## 接入前必须完成

需要完成跨连接事件监听、服务端订单/成交/括号状态完整性与来源证明、运行控制器和界面接入、每个跟随账户的独立暂停/重连状态、改单撤单及部分成交竞态、主退出后同步、保护单关系核验，以及带故障注入的集成测试。两腿 OSO 的券商 OCO 行为未经过真实 Demo 验证；不得仅凭订单有同一父单就认定它们互相取消。还需确认自动平仓接口在版本变化和并发成交下不会关闭不属于跟单的仓位。完成离线验证后，先用不影响考核的专用 Demo 账户验证，不连接真实资金账户。
